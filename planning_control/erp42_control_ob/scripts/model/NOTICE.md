# Third-party code

The `model/` package is the LaneNet (ENet / U-Net / DeepLabv3+) implementation from
[IrohXu/lanenet-lane-detection-pytorch](https://github.com/IrohXu/lanenet-lane-detection-pytorch)
(commit `0e5aa37`), MIT License — see `LICENSE` in this directory.
It is vendored unmodified so that `lane_detector.py` can import it.
