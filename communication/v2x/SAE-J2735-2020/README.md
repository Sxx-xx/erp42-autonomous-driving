# SAE J2735 ASN.1 definitions

`v2x_decoder.py` compiles every `*.asn` file in this directory with `asn1tools` (UPER).
The ASN.1 files are copyrighted by SAE International and are therefore not redistributed here.

1. Download the J2735 ASN.1 package from <https://www.sae.org/standards/content/j2735asn_202007/>
2. Extract the `J2735-*.asn` files into this directory.
